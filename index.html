AI for your own code

The 159 problems from the sheet never need a key, and neither does pasted Python: it runs for real in your browser. A key is used to trace other languages, to add an AI overview and edge cases to your Python, and for Ask.

You're viewing this inside claude.ai, so your own code is traced with your Claude account. claude.ai pages can't contact other AI services; to use an OpenRouter key, open the GitHub Pages version of AlgoScope.

Unticked, the key is kept only until you close this tab. Either way it stays in this browser and is sent only to openrouter.ai. Tip: set a credit limit of $0 on the key at openrouter.ai, so it can only use free models.

  1. Go to openrouter.ai and sign in (Google or GitHub works). No card needed.
  2. Open Settings → API Keys and press Create key. Give it a name like "AlgoScope".
  3. Copy the key (it starts with sk-or-v1-). It's shown only once.
  4. Paste it above and press Save, then pick a model ending in :free.

Free limits: about 20 requests a minute and 50 a day (1,000 a day once you've ever bought $10 of credits). One trace is one request. Free models are less accurate than Claude, so double-check surprising traces.
